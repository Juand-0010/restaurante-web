# Brasa Norte

Pagina web estatica para un restaurante con menu, carrito de compras y simulacion de pedido.

## Como abrirla

Abre `index.html` directamente en el navegador.

## Funciones

- Menu por categorias.
- Agregar, quitar y cambiar cantidades en el carrito.
- Carrito guardado en `localStorage`.
- Calculo de subtotal, envio y total.
- Formulario de checkout.
- Simulacion de pedido con numero de orden y estados.

## Publicacion en GitHub

Este proyecto ya esta listo como repositorio Git local. Para publicarlo, crea un repositorio vacio en GitHub y ejecuta:

```powershell
git remote add origin URL_DEL_REPOSITORIO
git branch -M main
git push -u origin main
```
